# VetOS Caribbean

A mobile-first veterinary clinic directory, pet owner portal and appointment-management platform for Trinidad and Tobago.

## Technology
- Next.js App Router, TypeScript, Tailwind CSS
- Supabase PostgreSQL and Auth (planned)
- Vercel (planned deployment)

## Local setup
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## MVP scope
1. Public veterinary directory and verified clinic profiles
2. Free pet profiles and veterinarian-supplied vaccination dates
3. Appointment requests and clinic confirmation
4. Clinic-scoped staff dashboard and administration

## Important
The initial homepage is a prototype. No booking, login or clinical records are live.
Do not use real pet-owner/patient data until tenant isolation, consent, access control, backups and independent security review are complete.

See AGENTS.md for Codex working instructions.
